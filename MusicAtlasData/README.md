# 公开人工分类配置

`classifications.json` 是作者在真实使用中保存的全部人工分类修正，经作者明确授权随源码和安装包公开。它不是演示样例，也不是网易云官方分类结果。

2026-11-08 的最新快照包含 53 首歌曲的人工覆盖：曲风 36 条、气质 21 条、来源 7 条，同一首歌曲可包含多个维度。空数组表示作者手动清空该维度，导入时也予以保留。包括新增的 III (Find Yourself) 修正。

文件仅包含歌曲 ID、类别目录、维度修正及地图展开配置；没有登录凭据、Cookie、歌单快照或音源地址。按歌曲 ID 匹配，因此在其它歌单中遇到同一首歌曲时也会生效。人工修正反映作者的判断，可以在音乐地图中继续调整或按维度恢复自动分类。

发布 ZIP 中的安装脚本只在目标设备尚无分类状态文件时自动载入。已有配置保持原样；主动替换时，关闭 HyPlayer，再运行发布包内的 `Transfer-AtlasSettings.ps1 -Mode Import -Path .\classifications.json`，脚本会先备份目标设备的配置。

`mood-curation.json` 是另一层共享逐曲校正，按具体歌曲 ID 增删气质标签，包含理由和审阅时的平台标签。它不是个人配置快照，不写入 `overrides`，不会覆盖设备上的手动修改；空数组的个人清空也优先。该表在构建时嵌入地图 HTML，因此已有设备升级即可使用，无需导入整套个人配置。修改此表后运行 `node MusicAtlasBuild/build-hyplayer-atlas.cjs` 并发布资源更新。

首批 55 首的变更与尚未应用的候选见 [气质审阅清单](mood-curation-review.md)。这里只公开实际审阅的曲目信息，不包含整份私人歌单、音频或账号信息。判断基于已知作品和录音元数据，不代表完成了整库试听。
